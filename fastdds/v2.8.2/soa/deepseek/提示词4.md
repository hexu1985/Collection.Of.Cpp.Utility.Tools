我现在要写一篇详细设计文档，编程语言为C++，题目是基于fastdds实现的SOA框架，主要是实现RPC service和RPC client。
我目前做如下设计：
首先是服务名维护在fastdds的TOPIC里，不同的服务对应不同的TOPIC，以服务ServiceA为例，在fastdds中定义soa.rpc.ServiceA.request和soa.rpc.ServiceA.response这两个TOPIC，请求和响应的TOPIC对应的idl定义如下：
module soa_on_dds {

enum ErrorCode {
    SUCCESS,
    OTHER_ERROR, 
    SERIALIZE_FAILED,
    DESERIALIZE_FAILED,
    SERVICE_NOT_AVAILABLE,
    METHOD_NOT_REGISTER,
    REQUEST_TIMEOUT
};

struct RPC_Header {
    string method_name;
    string client_id;
    long session_id;
    long request_id;
};

struct RPC_Request {
    RPC_Header header;
    sequence<octet> request_payload;
};

struct RPC_Response {
    RPC_Header header;
    ErrorCode error_code;
    sequence<octet> response_payload;
};

};  // soa_on_dds
每个请求header里包含method_name，区分同一个服务下的不同rpc调用，header里包含client_id来区分不同的rpc client，session_id和request_id分别对应client的生命周期和rpc调用的生命周期。
给出详细设计文档。

RPC client接口定义如下：
class RpcClient {
public:
    RpcClient(const std::string& client_id, const std::string& service_name);

    void init();

    template <typename Argument, typename Result>
    int call(const std::string& method_name, const Argument& arg, Result& res);

    template <typename Argument, typename Result>
    void async_call(const std::string& method_name, const Argument& arg,
            std::function<void(int, std::shared_ptr<Result>)> call_back);

    template <typename Argument, typename Result>
    int call_timed(const std::string& method_name, const Argument& arg, Result& res, std::chrono::milliseconds timeout);

    template <typename Argument, typename Result>
    void async_call_timed(const std::string& method_name, const Argument& arg,
            std::function<void(int, std::shared_ptr<Result>)> call_back, std::chrono::milliseconds timeout);
};

}   // namespace fastdds_soa

RPC service定义如下：
namespace fastdds_soa {

class RpcService {
public:
    RpcClient(const std::string& service_name);

    template <typename Argument, typename Result>
    void register_method(const std::string& method_name,
            std::function<void (const Argument&, Result& )> process_function);

    void unregister_method(const std::string& method_name);

    void start();
    void stop();
};

}   // namespace fastdds_soa
其中重要的点是：payload为string，模板类型Argument和Result只要支持SerializeToVector和DeserializeFromVector两个方法，将类型序列化成std::vector<uint8_t>和从std::vector<uint8_t>反序列化，就可以通过模板函数里自动将完成request_payload和response_payload字段的序列化和反序列化。
