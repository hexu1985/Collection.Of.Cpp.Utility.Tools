Fast DDS 2.14.7 纯源码依赖编译时，其核心库和主要第三方依赖的对应版本如下：

### 核心库依赖
| 依赖库 | 推荐版本 |
| :--- | :--- |
| **Fast CDR** | v2.2.8  |
| **Foonathan Memory** | v0.7-3  |
| **Asio** | v1.18.1  |
| **TinyXML2** | v6.0.0  |
| **googletest**  | v1.13.x（主要针对单元测试）   |
| **OpenSSL** | v3.1.1（主要针对安全功能）  |

### 构建工具与编译器
*   **CMake**：最低要求 **3.20** 。
*   **GCC**：根据你的操作系统，建议 GCC 9 至 11.4 之间的版本 。

需要注意的是，以上版本信息是基于 Fast DDS 2.14.x 分支的官方文档整理的。虽然这些是官方推荐搭配的版本，但在实际编译时，部分库（如 OpenSSL、Asio）也可以尝试使用系统包管理器提供的兼容版本。
